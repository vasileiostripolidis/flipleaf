# Privacy Policy — Flipleaf

*Effective 3 November 2026*

**Short version: Flipleaf collects nothing.**

- Flipleaf has no accounts, no analytics, no telemetry, no crash reporting, no advertising and no tracking.
- Your documents are opened, edited and saved only on your own device. They are never uploaded anywhere.
- Your settings, recent files list and saved signatures are stored only on your device. You can delete them at any time. On Windows, the uninstaller offers to delete them; in the web version, clear the site data in your browser.
- The desktop app connects to the internet only when you click a web link inside a document (it opens in your own browser), and to check GitHub for a newer version. The update check sends no personal data or documents; GitHub sees your IP address, as with any web request. Turn it off in *Help → Check for updates automatically*.
- The web version (vasileiostripolidis.github.io/flipleaf) is hosted by GitHub Pages. GitHub may log technical data such as IP addresses under the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Documents you open in the web version stay in your browser and are not sent to GitHub or to anyone else.
- Downloads are served by GitHub Releases, under the same GitHub Privacy Statement.

Because Flipleaf does not collect personal data, there is no personal data for us to access, correct, delete or share.

Questions: https://github.com/vasileiostripolidis/flipleaf/issues

## Πολιτική απορρήτου — Flipleaf

*Ισχύει από 3 Νοεμβρίου 2026*

**Με λίγα λόγια: το Flipleaf δεν συλλέγει τίποτα.**

- Δεν υπάρχουν λογαριασμοί, στατιστικά, τηλεμετρία, αναφορές σφαλμάτων, διαφημίσεις ή παρακολούθηση.
- Τα έγγραφά σου ανοίγουν, τροποποιούνται και αποθηκεύονται μόνο στη συσκευή σου. Δεν ανεβαίνουν ποτέ πουθενά.
- Οι ρυθμίσεις, η λίστα πρόσφατων αρχείων και οι αποθηκευμένες υπογραφές σου μένουν μόνο στη συσκευή σου και μπορείς να τα διαγράψεις όποτε θέλεις. Στα Windows το πρόγραμμα απεγκατάστασης προσφέρεται να τα διαγράψει. Στην έκδοση web, διαγράφεις τα δεδομένα του ιστότοπου από τον browser σου.
- Η εφαρμογή υπολογιστή συνδέεται στο διαδίκτυο μόνο όταν κάνεις κλικ σε σύνδεσμο μέσα σε έγγραφο (ανοίγει στον δικό σου browser) και για να ελέγξει στο GitHub αν υπάρχει νεότερη έκδοση. Ο έλεγχος δεν στέλνει προσωπικά δεδομένα ή έγγραφα· το GitHub βλέπει τη διεύθυνση IP, όπως σε κάθε σύνδεση. Τον απενεργοποιείς από *Βοήθεια → Αυτόματος έλεγχος για ενημερώσεις*.
- Η έκδοση web (vasileiostripolidis.github.io/flipleaf) φιλοξενείται από το GitHub Pages. Το GitHub μπορεί να καταγράφει τεχνικά δεδομένα, όπως διευθύνσεις IP, σύμφωνα με τη [δήλωση απορρήτου του GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Τα έγγραφα που ανοίγεις στην έκδοση web μένουν στον browser σου και δεν αποστέλλονται στο GitHub ή σε κανέναν άλλον.
- Οι λήψεις γίνονται από το GitHub Releases, με την ίδια δήλωση απορρήτου του GitHub.

Επειδή το Flipleaf δεν συλλέγει προσωπικά δεδομένα, δεν υπάρχουν δεδομένα σου στα οποία να έχουμε πρόσβαση, να διορθώσουμε, να διαγράψουμε ή να μοιραστούμε.
